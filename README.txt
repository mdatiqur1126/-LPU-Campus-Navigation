LPU CAMPUS NAVIGATOR — STUDENT PROJECT DEMO
===========================================

WHAT'S INCLUDED
- index.html: website structure
- style.css: layout, colours and responsive styling
- script.js: destination selection, sample directions and demo feedback

HOW TO RUN IT
1. Download and extract lpu_campus_navigator.zip.
2. Open the extracted folder.
3. Double-click index.html to open the website in Chrome, Safari or Firefox.
4. Choose a destination and click "Find route".
5. Try the feedback buttons at the bottom.

NO INSTALLATION REQUIRED
This is a front-end website using HTML, CSS and JavaScript. It does not require a server, database, login, API key or special software.

IMPORTANT PROJECT NOTE
This website is a prototype for the INT335 Design Thinking project. All displayed locations, route steps, walking times and map positions are illustrative examples only and are NOT verified LPU directions. Before presenting a route as real, visit the campus, verify the route and landmarks, and update the route data in script.js and the map in index.html/style.css.

HOW TO ADD OR CHANGE DESTINATIONS
Open script.js in a text editor. The "routes" object contains the destination examples and direction steps. Edit the name, time, destination, steps and path for each route. Use only routes you have verified. The schematic map is a simplified visual, not a real campus map.

FOR YOUR REPORT / PRESENTATION
You can explain that the prototype lets a user:
1. Select an example destination.
2. View step-by-step directions.
3. See a schematic route and landmarks.
4. Submit simple feedback on clarity.

The feedback is only shown on the current page; it is not saved to a database.
